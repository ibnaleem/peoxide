# peoxide

A Python library that reads Windows PE files the way pefile does, with the parsing done in Rust.

## Language

### Measuring against pefile

**Parity**:
A peoxide value that equals, field by field, what the pinned pefile release reports for the same file.
_Avoid_: compatibility, matching

**Sweep**:
A parity check over every PE file in a folder, such as System32.
_Avoid_: scan, audit

**Deliberate difference**:
A documented place where peoxide reports the file as it is and pefile does not.
_Avoid_: deviation, incompatibility

**Extension**:
An attribute or method peoxide offers that pefile lacks, such as TLS callbacks or the security directory.
_Avoid_: extra, add-on

### Test inputs

**Fixture**:
A small synthetic PE file, generated by a script and committed, so tests run without Windows system files.
_Avoid_: sample, test binary

**Crash input**:
A malformed file that once made the parser panic or hang, kept so it never does again.
_Avoid_: crasher, repro

### PE structure

**Directory**:
One of the sixteen data-directory slots in the optional header, together with the structure it points to.
_Avoid_: table

**Absent directory**:
A directory whose slot is empty or points at data that cannot be read.
_Avoid_: missing directory

**Security directory**:
The directory holding the file's attribute certificates; unlike every other directory, its address is a file offset, not an RVA.
_Avoid_: certificate directory, signature table
